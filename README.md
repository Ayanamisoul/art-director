# Арт-директор

AI-агент для генерации дизайн-материалов (презентации, лендинги) по запросу менеджера без технических навыков.
Учебный проект, Московский Политех. Заказчик: Актион.

## Ключевые принципы

- **Дёшево, маленькая модель, суверенно** — локальные/российские модели, не зарубежные API.
- **Local-first хранение** — все файлы (брендинг, презентации, результаты) живут на машине пользователя.
  Сервер презентации НЕ хранит: он получает входные данные, генерирует и отдаёт результат обратно.
- **Гибкий агент, не жёсткий пайплайн** — LLM сама выбирает инструменты и скиллы.

## Текущий локальный стенд (ноябрь 2026)

| Компонент | Что стоит | Зачем |
|---|---|---|
| Рантайм моделей | Ollama | Запускает LLM локально, даёт OpenAI-совместимый API на `http://localhost:11434` |
| Модель | `qwen2.5:7b-instruct` (~4.7 ГБ) | Основная. У заказчика в Актионе развёрнут Qwen — промпты перенесутся |
| Модель-бейзлайн | `llama3.1:8b` | Для сравнения качества |
| Харнесс (чат UI) | Open WebUI в Docker | Чат-интерфейс как у ChatGPT поверх Ollama: `http://localhost:3000` |

## Структура репозитория

- `docs/` — архитектура, решения, конспекты
- `prompts/` — эксперименты с промптами (запрос → результат → выводы)
- `agent/` — код агента (появится позже)
- `data/` — НЕ коммитим: локальные файлы пользователей, брендинг, результаты

## Быстрый старт

```bash
# 1. Модель (один раз)
ollama pull qwen2.5:7b-instruct

# 2. Ollama должен слушать не только localhost, иначе Docker до него не достучится.
#    Переменная OLLAMA_HOST=0.0.0.0 уже прописана в системе (setx), при автозапуске
#    Ollama подхватит её сам. Если что-то пошло не так — запусти вручную:
scripts\start-ollama.bat

# 3. Харнесс
docker start open-webui   # дальше http://localhost:3000

# 4. Проверка модели из терминала
ollama run qwen2.5:7b-instruct "Привет"
```

> Нюанс: при OLLAMA_HOST=0.0.0.0 API модели доступен всей локальной сети.
> Для домашнего Wi-Fi это ок, в общественных сетях — учитывай (файрвол).
