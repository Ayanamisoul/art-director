# MCP и естественный язык в архитектуре агента

## Проблема, которую решаем
Менеджер пишет по-человечески: «сделай лендинг для кофейни, потеплее и с меню».
Никаких строгих форм. При этом у агента есть настоящие действия: сгенерировать HTML,
сконвертировать в PDF, сохранить файл, взять логотип компании.

## Что такое MCP простыми словами
**MCP (Model Context Protocol)** — стандарт «розетки» для инструментов.
Аналогия: USB-C для ИИ. Не важно, что за устройство (инструмент) — если у него
разъём USB-C (MCP), его можно воткнуть в любой хаб (агент).

- **MCP-сервер** = маленькая программа, которая объявляет: «у меня есть инструменты
  `html_to_pdf`, `save_file`, `get_brand_assets` — вот их параметры».
- **MCP-клиент** (внутри нашего агента) подключается к серверам и узнаёт список инструментов.
- **LLM** не знает про MCP вообще. Она просто говорит: «вызови `html_to_pdf`
  с таким-то аргументом». Клиент ловит это и передаёт в MCP-сервер.

```
Пользователь (естественный язык)
   ▼
Наш агент (Python)
   │  1. спросил у MCP-серверов список инструментов
   │  2. отдал LLM запрос + описания инструментов
   ▼
Qwen ──► «хочу вызвать html_to_pdf(html=...)»
   │
   ▼
Агент ──► MCP-сервер "files/pdf" ──► готовый PDF на диске пользователя
   │
   ▼
Ответ пользователю + ссылка на файл
```

## Почему это сочетается с «пониманием человеческого языка»
Понимание делает LLM, а не правила. Наш код НЕ парсит фразу пользователя регулярками.
Вместо этого:
1. Промпт агента описывает роль («ты арт-директор, помогаешь менеджеру...»)
   и КОГДА каким инструментом пользоваться.
2. Модель сама решает: уточнить детали, генерировать, или вызвать инструмент.
3. Роутер (презентация/лендинг) — тоже маленький LLM-вызов, а не if-else по ключевым словам.

Важное ограничение: Qwen2.5-7B умеет function calling (формат tool calls),
но мелкие модели ошибаются в аргументах → поэтому в архитектуре есть
блок валидации, а инструменты делаем «транзакционными»: один вызов = один
проверяемый результат.

## Какие MCP-серверы нам понадобятся (черновик)
| Сервер | Инструменты | Примечание |
|---|---|---|
| `artifacts` | `save_html`, `html_to_pdf`, `html_to_pptx` | конвертация — кодом, не моделью |
| `brand` | `get_logo`, `get_palette`, `save_brand_assets` | файлы пользователя, local-first |
| `templates` | `list_templates`, `get_template` | эталоны Актиона (2-й семестр, сценарий 1) |

Сервер — это ~50 строк на Python (`mcp` SDK) или Node. Начнём с одного
(`artifacts`), когда дойдём до своего агента.
