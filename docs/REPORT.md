# Арт-директор — отчёт о работе

**Ссылка на репозиторий:** https://github.com/Ayanamisoul/art-director
**Локальный запуск:** `cd agent && py -m uvicorn web:app --port 8000` → http://localhost:8000
**Стек:** Python · FastAPI · python-pptx · PyMuPDF · PowerPoint COM (рендер/экспорт) · MCP · LLM Z.ai GLM 5.3 Flash. Всё работает локально на машине пользователя, данные — в `data/` (в .gitignore), ключ — в `.env`.

## Требования заказчика (Актион, учебный проект Московский Политех)
1. AI-агент: менеджер на естественном языке получает презентации и лендинги.
2. **MCP-сервер** — обязательное требование (Актион использует Qwen; должна быть возможность подключить любой LLM-клиент).
3. **Валидация результата**: код → LLM-судья → человек.
4. Экспорт в PDF.
5. Local-first: всё крутится на машине пользователя, без облаков.

## Что сделано

### Ядро агента
- Чат-цикл с инструментами: модель сама решает, когда сохранить презентацию/лендинг.
- Один бэкенд LLM — Z.ai · GLM 5.3 Flash (селектор моделей убран по решению пользователя).
- **MCP-сервер** — тонкий адаптер над `core/` (создание презентаций/лендингов, чтение ассетов). Приложение от MCP не зависит — можно подключить любой MCP-клиент.
- **Судья (semantic_check)**: сравнивает сохранённый артефакт с запросом, возвращает замечания; агент исправляет в цикле до 3 попыток. Fail-open: недоступный судья не блокирует работу.
- **Валидатор структуры**: лимиты строк/символов, расчёт переносов («после переносов ~12 строк — не влезет»), проверка длины титула/подзаголовка, схемы stats/cards/font_size. Замечания уходят модели на доработку.

### Сборка презентаций (.pptx)
- **Работа по скелету шаблона .pptx**: слайды шаблона сохраняют дизайн, подкладывается только наш контент. Позиционная раскладка: первый лист — титул, последний — финал, средние — контент; недостающие клонируются с дизайном.
- **Карта дизайна шаблона**: фирменный шрифт (layout → master → txStyles) и **детект логотипа** (растеризация, компактные кластеры в углах, отсев линий) с кэшем по mtime. Цифры/карточки/картинки не наезжают на лого и декор.
- **Расчёт объёма текста**: оценка переноса строк по ширине бокса и кеглю; авто-ужмение шрифта от реального кегля шаблона; normAutofit как страховка. Модель может задавать кегль сама (`font_size: 12–40`).
- **Богатые слайды**: подпункты (`{text, sub}`), крупные цифры (`stats`), рамки (`frame`), карточки-«окошки» (`cards` 2–4), линейка под заголовком (только однострочным и если у шаблона нет своего декора в этой зоне).
- **Картинки**: пользовательские вставляются справа от текста с согласованной геометрией (текст сжимается с учётом левого края бокса), картинки шаблона детектируются и текст их обходит, пустые picture-плейсхолдеры удаляются, фото из шаблона — только по явной настройке.
- **Титульник**: перенос строк включён, ширина зоны нормализована, кегль подгоняется, ничего не обрезается.
- **Эмодзи** вырезаются из контента (и запрещены в промпте) и убраны из интерфейса.
- **PDF-шаблоны** поддержаны (растеризация страниц в фоны, вырезка чужого текста/фото), pptx — основной формат.

### Интерфейс
- Веб-чат (FastAPI + vanilla JS): drag&drop и Ctrl+V файлов, статусы загрузки, превью результата настоящим рендером (PPTX→PDF→PNG), кнопки «Редактировать», «чат», «Скачать PDF».
- Выбор шаблона пользователем (селект + `.preferred`), «без фото из шаблона», формат результата (авто/презентация/лендинг).
- Панели: файлы, чаты (создание/удаление/восстановление по ссылке), картинки (миниатюры, удаление).
- Редактор презентаций (тексты слайдов) с PDF-экспортом.

### Прочее
- PDF-экспорт через PowerPoint COM (`scripts/pptx2pdf.ps1`).
- Превью-рендер любого артефакта, натуральная сортировка страниц.
- Чистый рефакторинг: `core/` (sessions/templates/assets/artifacts/decks/previews) + `routers/` + тонкий `web.py`, фронт разделён (style.css/app.js).
- Документация: `docs/architecture.md`, `docs/mcp-and-natural-language.md`, докстринги инструментов MCP.

## Что проверить (чек-лист перед показом)
1. Сервер: `py -m uvicorn web:app --port 8000` (порт 8000 бывает занят другими программами — проверять по содержимому страницы, не только по коду ответа).
2. Новая презентация по запросу с деталями (цифры + «карточками» + подпунктами) — модель должна применить embellishment уместно.
3. Слайды с картинками (загрузить своё изображение) — текст не должен наезжать на картинку и лого.
4. Плотный слайд (много материала) — шрифт ужмётся или модель разделит на два слайда.
5. Титульный лист — заголовок/подзаголовок целиком в зоне дизайна, ничего не обрезано.
6. Замена шаблона через селект — пересборка на другом шаблоне, лого/шрифт подхватятся.
7. PDF-экспорт из чата и редактора.
8. Редактирование: правка текста слайда не теряет новые поля (stats/cards).
9. Подключение внешнего MCP-клиента (`test_mcp.py`, докстринги в `agent/mcp_servers/`).

## Известные ограничения
- Детект лого — эвристика (плотные кластеры в углах): монохромный лого на пёстром фоне может быть не найден.
- Оценка переносов — приближённая (средняя ширина символа); страховка — normAutofit и валидатор.
- PDF-экспорт требует установленного PowerPoint; на машинах без него недоступен.
- Мёртвый код PDF-механики в pptx_builder оставлен сознательно (возможный возврат требования).
