# Архитектура локального стенда (v0, ноябрь 2026)

## Зачем что стоит — объяснение для команды

### Ollama — «движок» для моделей
Ollama — это сервер, который запускает LLM у вас на машине.
Аналогия: Ollama — как PostgreSQL для баз данных, только для нейросетей.

- Качает модели командой `ollama pull <имя>` (лежат в `C:\Users\<юзер>\.ollama`).
- Поднимает API на `http://localhost:11434`.
- Важно: API **OpenAI-совместимый** (`/v1/chat/completions`) — значит, наш код агента
  сможет работать и с локальной Ollama, и с Qwen на сервере Актиона, просто поменяв URL.

### Qwen2.5-7B-Instruct — сама модель
- 7 млрд параметров, квантована до ~4.7 ГБ (Q4) — помещается в 8 ГБ видеокарты.
- `Instruct` = обучена следовать инструкциям (то, что нужно для агента).
- Выбрана потому, что у заказчика (Актион) развёрнут Qwen — наши промпты потом перенесутся.

### Open WebUI — харнесс (чат-интерфейс)
**Харнесс (harness)** — это «обвязка» вокруг модели: чат-окно, история диалогов,
системные промпты, загрузка файлов. Модель сама по себе — просто функция «текст → текст»;
харнесс превращает её в продукт, с которым может работать человек.

Open WebUI — готовый open-source харнесс, как ChatGPT, но локальный:
- Работает в Docker-контейнере, открывается на `http://localhost:3000`.
- Подключается к Ollama автоматически.
- Позволяет сохранять системные промпты и тестировать их — это наши «эксперименты с промптами».
- Позже заменим своим агентом (Python), а пока — быстрый стенд для опытов.

## Схема

```
Браузер (менеджер)
   │  http://localhost:3000
   ▼
Open WebUI (Docker)   ← харнесс: чат, промпты, история
   │  http://localhost:11434/v1  (OpenAI-совместимый API)
   ▼
Ollama                ← движок моделей
   │
   ▼
Qwen2.5-7B-Instruct   ← модель (веса на диске, инференс на GPU)
```

Позже вместо Open WebUI будет свой агент:
`Веб-фронт → FastAPI → Роутер → Скилл (промпт+инструменты) → Ollama/Qwen Актиона → Валидация → HTML→PDF`

## Local-first: где что хранится

| Данные | Где | Комментарий |
|---|---|---|
| Веса моделей | `~/.ollama` | ~9 ГБ |
| Чаты/промпты Open WebUI | Docker-том `open-webui` | на машине пользователя |
| Брендинг, презентации, результаты | `data/` у пользователя | сервер НЕ хранит файлы |
| Промпты и код | этот репозиторий | то, что переносимо между машинами |

## Local-first ассеты пользователя (ноябрь 2026)

- `data/assets/` — изображения, загруженные пользователем (логотипы, фото).
  Модель видит список через MCP-инструмент `list_images` и может ставить
  картинку на текстовый слайд (поле `image`).
- `data/templates/` — свои `.pptx`-шаблоны. Модель видит их через `list_templates`;
  параметр `template` в `save_presentation` подставляет тему/мастер шаблона
  (акцентный цвет берётся из `ppt/theme/theme1.xml`, слайды шаблона удаляются).
- Веб: `POST /api/assets`, `POST /api/templates` (загрузка), `GET` — списки.
- Редактор: живой предпросмотр на всю ширину, авто-сжатие шрифта при >3 пунктов,
  выбор картинки для слайда.
