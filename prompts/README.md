# Эксперименты с промптами

Каждый эксперимент — отдельный `.md` файл. Формат:

```markdown
# YYYY-MM-DD — короткое название

**Модель:** qwen2.5:7b-instruct
**Задача:** сценарий 2 (генерация по описанию) — лендинг

## Промпт
<текст системного/пользовательского промпта>

## Результат
<что выдала модель; файл результата, если есть>

## Выводы
- что получилось / что нет
- что поменять в промпте в следующий раз
```

Цель первой недели: понять, насколько хорошо qwen2.5:7b генерирует
одностраничный HTML-лендинг и HTML-презентацию, и какие инструкции в промпте
реально влияют на результат.
