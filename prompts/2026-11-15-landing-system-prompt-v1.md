# 2026-11-15 — лендинг кофейни, с системным промптом v1

**Модель:** qwen2.5:7b-instruct
**Задача:** сценарий 2 — лендинг (тот же запрос, что в бейзлайне)
**Отличие:** добавлен системный промпт с жёсткими правилами (см. ниже)

## Системный промпт v1
Ты — генератор дизайн-макетов... Правила: (1) только HTML без ```-обёрток и пояснений;
(2) запрет внешних ресурсов, вместо фото — CSS-градиенты/эмодзи; (3) стили в одном
`<style>` в head; (4) русский язык без смешения кириллицы/латиницы; (5) обязательная
структура hero + секции + подвал; (6) палитра, скругления, тени, отступы ≥24px.

## Результат — сравнение с бейзлайном

| Проверка | Бейзлайн | С системным промптом |
|---|---|---|
| Чистый HTML без ```-заборов | ❌ | ✅ первый символ `<` |
| Без внешних URL | ❌ placeholder.com | ✅ |
| Стили в `<style>` | частично | ✅ |
| Орфография (кириллица/латиница) | ❌ «маккиацchio» | ✅ |
| Валидность, завершённость | ✅ | ✅ 835 ток / 18 сек |

Дизайн заметно лучше: кнопка-«таблетка» с акцентным цветом, карточки меню
со скруглениями, знак ₽ вместо «р.».

## Что ещё не идеально
1. Блок контактов свёлся к подвалу с копирайтом — адрес/телефон потерялись.
   Усилить правило 5: перечислить обязательные секции явно.
2. Визуально всё ещё «просто»: одна колонка, мало воздуха в hero.
   Кандидат на few-shot: показать модели 1 эталонный HTML в промпте.

## Вывод
Системный промпт снимает ВСЕ инфраструктурные проблемы бейзлайна
(заборы, внешние ресурсы, опечатки) — их не придётся чинить кодом.
Дальше качество упирается в «дизайнерский вкус» модели → few-shot на
эталонах Актиона, когда они появятся.
